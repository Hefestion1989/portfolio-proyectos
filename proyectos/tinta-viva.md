# Tinta Viva

Tinta Viva es una aplicación de escritorio local-first para narradores, escritores y personas que quieran experimentar libremente con personajes, universos, roleplay y continuidad narrativa.

La aplicación está construida con .NET 10, Avalonia y SQLite. Se conecta a servidores compatibles con la API de OpenAI y está preparada para trabajar con LM Studio. Historias, personajes, recuerdos e imágenes permanecen en el equipo del usuario.

## Escritura libre y privada

Tinta Viva admite narrativa general, romance y contenido erótico o explícito entre personajes adultos. No agrega filtros de contenido ni depende de una nube propia: la respuesta concreta depende del modelo local que el usuario elija y configure.

Su foco está en construir personajes persistentes, vínculos, psicología, escenas y mundos con memoria. Para una experiencia especializada en relatos y roleplay adulto existe [Tinta Privada](tinta-privada.html), un proyecto independiente que no comparte su almacenamiento.
